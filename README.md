# Práctica Front-End Expo

## Descripción

Aplicación desarrollada con Expo, React Native y TypeScript, enfocada en la construcción de una interfaz moderna, organizada y funcional.

El proyecto fue mejorado visualmente para ofrecer una mejor experiencia de usuario, manteniendo intacta la lógica original de funcionamiento. Se reorganizaron algunos componentes dentro del menú principal para facilitar la navegación y mejorar la presentación general de la aplicación.

---

## Objetivos

- Mejorar la experiencia visual del usuario.
- Mantener la funcionalidad original del proyecto.
- Aplicar una interfaz moderna y limpia.
- Organizar mejor los componentes dentro del menú principal.
- Implementar buenas prácticas de estructura y documentación del código.

---

## Características Principales

- Diseño moderno y minimalista.
- Paleta de colores en tonos grises.
- Menú principal reorganizado.
- Calculadora independiente dentro del menú.
- Modal accesible desde una opción específica del menú.
- Componentes reutilizables.
- Navegación intuitiva.
- Código documentado para facilitar el mantenimiento y la sustentación del proyecto.
- Interfaz responsive compatible con dispositivos móviles.

## Instalación

### Clonar el repositorio

```bash
git clone URL_DEL_REPOSITORIO
```

### Ingresar al proyecto

```bash
cd nombre-del-proyecto
```

### Instalar dependencias

```bash
npm install
```

---

## Ejecución

Iniciar el proyecto en modo desarrollo:

```bash
npx expo start
```

Ejecutar en Android:

```bash
npm run android
```

Ejecutar en iOS:

```bash
npm run ios
```

Ejecutar en navegador:

```bash
npm run web
```

## Funcionalidades

### Menú Principal

Permite acceder a las diferentes funcionalidades de la aplicación mediante una interfaz organizada y fácil de utilizar.

### Calculadora

La calculadora se encuentra disponible como una sección independiente dentro del menú principal, permitiendo realizar operaciones de manera cómoda y ordenada.

### Modal Informativo

El modal fue separado dentro del menú para facilitar su acceso y mejorar la organización visual de la aplicación.

### Componentes Reutilizables

La aplicación está construida utilizando componentes independientes que facilitan la escalabilidad y el mantenimiento del código.
